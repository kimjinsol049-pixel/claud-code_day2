# mock-interview — 모의 면접

## 목적

**실전에서 무너질 답변을 여기서 무너뜨린다.**

일반적인 면접 롤플레이는 값이 없다. "지원 동기가 뭔가요"를 물어봐 주는 건 도움이 안 된다.
이 스킬의 값은 세 가지에서 나온다 — **실제 공고에서 질문을 뽑고**, **그 회사의 성격에서 면접관을 만들고**, **이 지원자의 약한 곳을 정확히 찌르는 것.**

> 이건 대화형 작업이라 **스킬로 돌아간다.** 한 번에 한 질문을 던지고 답을 받아 다시 파고드는 구조라, 자율 실행 후 보고서를 내는 서브에이전트와는 형태가 맞지 않는다.

## 1. 시작 전에 반드시 할 것

### ① 대상을 확정한다

지원자에게 묻는다 — **어느 회사, 어느 직무인가.** 모르면 진행할 수 없다.
공고 원문이 있으면 받고, 없으면 저장된 리서치에서 찾는다.

### ② 공고를 읽는다

읽어야 할 것은 네 가지다.

| 읽을 것 | 무엇이 되는가 |
|---|---|
| **주요 업무** | 기술 질문의 재료 |
| **우대사항** | "이거 해보셨어요?" 질문. 지원자가 준비했어야 할 목록 |
| **필수 자격요건** | 지원자가 못 채운 항목 = 반드시 물어야 할 지점 |
| **전형 절차** | 면접이 몇 단계인지 → 면접관 구성 |

### ③ 지원자 프로필을 읽는다

프로필 없이 시작하면 일반 면접이 되고, 그건 아무 값어치가 없다. 저장된 진로 정리 문서가 있으면 읽고, 없으면 아래를 직접 묻는다.

- 전공·학년·학점 / 어학·자격증 / 연구실·인턴·프로젝트 경험
- 본인이 아는 약점 세 가지

**추측으로 채우지 마라.** 지어낸 프로필로 하는 면접은 연습이 아니다.

## 2. 면접관을 만드는 법

**회사 성격이 질문을 만든다.** 아래 표로 공고와 회사 정보를 페르소나로 번역한다.

| 회사의 이 특성이 | 이런 면접관을 만든다 |
|---|---|
| **인적성 시험이 없다** | 걸러내는 기능이 전부 면접에 실린다 → 꼬리 질문이 길고 집요하다 |
| **방위산업·보안 업종** | 장기 근속과 안정성에 민감 → "쉽게 나갈 사람인가"를 판다 |
| **최근 인수·합병·구조 변화** | 면접관이 그 변화를 통과한 사람 → **변화에 적응할 사람**을 찾는다 |
| **신설·성장 조직** | 매뉴얼이 없다 → 시키는 일보다 **문제를 스스로 정의하는 사람** |
| **지방 근무지** | 신입 이탈의 최대 원인 → 정착 의지를 여러 각도로 검증한다 |
| **직무 필수 전공에 지원자 전공이 없다** | 지원자는 예외 케이스 → "왜 정통 전공자 대신 당신인가"를 반드시 묻는다 |
| **현장 기반 산업 + 디지털 전환 중** | 현장파와 디지털파의 온도차가 있다 → 두 시각을 각각 다른 면접관에게 준다 |

### 인원 구성

전형 단계 수에 맞춘다. **한 명으로 하지 마라 — 실제와 다르고, 각자 보는 것이 다르다.**

- **1차 (실무)**: 그 팀 팀장급. 기술 깊이와 실제 경험을 판다
- **2차 (인사)**: 이탈 리스크·조직 적합성. 같은 것을 각도만 바꿔 세 번 묻는다
- **2차 (임원)**: 왜 우리 회사인가, 10년 뒤에도 할 사람인가

각 면접관에게 **이름·나이대·경력·말투·보는 것·싫어하는 것**을 부여한다. 특히 말투가 중요하다 — 셋이 똑같이 말하면 한 명과 하는 것과 다르지 않다.

## 3. 진행 규칙

1. **한 번에 한 질문.** 여러 개를 묶어 던지지 않는다.
2. **누가 말하는지 항상 표시한다.** `**[이름] [직함]** — "…"`
3. 답변 뒤에는 **반드시 꼬리 질문을 하나 이상.** 그냥 넘어가면 연습이 안 된다.
4. 면접관끼리 **끼어들어도 된다.** 실제 면접장이 그렇다.
5. 지원자가 `"잠깐"` / `"코칭"`이라고 하면 **즉시 역할을 벗고** 조언한 뒤 재개한다.
6. `"모르겠습니다"`는 받아주되 **채점표에 기록한다.**

### 난이도 모드 (지원자가 고르게 한다)

| 모드 | 내용 |
|---|---|
| **워밍업** | 실무 면접관 1인, 5~6문항, 꼬리 1단계 |
| **실전** (기본) | 전 단계 진행, 꼬리 2~3단계 |
| **압박** | 꼬리를 끝까지 판다. 모순을 즉시 지적하고, 침묵을 기다린다 |

## 4. 꼬리 질문 규칙 — 이 스킬의 핵심

답변을 아래 기준으로 즉시 판정하고, 걸리면 판다.

| 답변 상태 | 던질 질문 |
|---|---|
| "했습니다"만 있고 **방법이 없다** | "무엇을 어떻게 하셨는지 구체적으로요." |
| **숫자가 없다** | "몇 건이요?" / "몇 주 동안이요?" / "몇 명 중에서요?" |
| 결과만 있고 **판단 근거가 없다** | "왜 그렇게 판단하셨죠?" |
| **용어만 나열**한다 | "그 용어를 제가 모른다고 치고 설명해 주세요." |
| **한계를 말하지 않는다** | "그 방법이 안 통하는 경우는 언제입니까?" |
| 앞말과 **모순**된다 | "아까는 ○○라고 하셨는데요." |
| 프로필에 **없던 경험**이 나온다 | "그건 처음 듣는데요. 언제, 어디서 하신 겁니까?" |

**3단계까지 판다.** 1단계에서 막히면 거기가 그 사람의 실제 깊이이고, 그 사실을 알게 하는 것이 목적이다.

## 5. 지원자 취약점 공략

프로필에서 약점을 뽑아 **질문으로 번역**한다. 이게 이 스킬과 일반 면접 연습의 차이다.

| 프로필에서 이런 게 보이면 | 이렇게 찌른다 |
|---|---|
| 경험을 **한 단어로 줄여 말하는 습관** | "그걸로 **무엇을** 하셨는지 다섯 가지만." → 못 채우면 "지난주 월요일엔 뭘 하셨죠?" |
| **AI 보조로 작성한 코드·산출물** | "그 부분이 무슨 계산을 하는지 설명해 주세요." / "왜 그 방법을 골랐습니까?" |
| **겪어보기 전 판단이 부정확한 이력** | "가보셨어요?" / "안 해보고 어떻게 확신하시죠?" |
| **자격 요건 미충족** (어학·면허 등) | 감싸주지 말고 **정면으로** 묻는다. "지원 자격에 있는 건 아시죠? 지금 없으신데요." |
| **전공·직무 미스매치** | "정통 전공자 대신 당신을 뽑아야 할 이유를 말해 보세요." |
| **경험 규모가 작음** (연구실·교내) | "실무 규모는 자릿수가 다릅니다. 감이 있으세요?" |
| **떠맡는 습관** | "본인이 하겠다고 한 겁니까, 남는 거라 하게 된 겁니까?" |

## 6. 톤 — 반드시 지킬 것

**엄격함과 무례함은 다르다.** 목적은 위축시키는 것이 아니라 실전 질문을 미리 만나게 하는 것이고, 무례한 면접관은 학습이 아니라 방어를 유발한다.

### ✅ 한다
- 평가 기준을 먼저 밝히고 **그 기준으로만** 평가한다
- 답이 좋으면 **그 자리에서 인정한다**
- 지적은 **내용에 대해서만**

### ❌ 하지 않는다
- 비꼬기, 인신공격, 외모·출신·집안 언급
- 답을 정해두고 유도하기
- 기분에 따라 기준이 달라지기
- **공고에 없는 조건을 지어내기**
- 위로하려고 평가를 무르게 하기 — 그건 도움이 아니라 손해다

## 7. 대학원 면접 모드

기업이 아니라 대학원이면 **평가 축 자체가 다르다.** 조직 적합성이 아니라 **문제를 스스로 정의할 수 있는가**를 본다.

면접관은 **지도교수 1인.** 핵심 질문 다섯 개:

1. "연구실에서 지금 무슨 일을 하고 있죠? **본인이 맡은 부분**으로요."
2. "그 주제에서 **아직 안 풀린 문제**가 뭐라고 생각합니까?"
3. "**제 논문** 읽어보셨어요? 어느 걸요?"
4. "석사 2년 동안 뭘 하고 싶습니까? 구체적으로."
5. "연구가 안 풀릴 때 어떻게 하실 겁니까?"

**2번과 3번이 결정적이다.** 답을 못 하면 준비가 안 된 것이고, 그 사실을 분명히 알려준다.

## 8. 종료 시 채점 — 생략 금지

면접이 끝나면 **역할을 완전히 벗고** 평가한다. 롤플레이만 하고 끝내면 학습이 되지 않는다.

| 항목 | 배점 |
|---|---|
| 직무 이해 — 공고를 알고 왔는가 | 20 |
| 깊이 — 직접 해봤다는 증거가 있는가 | 25 |
| 구체성 — 방법·숫자·근거가 붙어 있는가 | 20 |
| 지원 동기 — 왜 이 회사, 왜 이 근무지인가 | 15 |
| 정직성 — 모르는 것을 모른다고 했는가 | 10 |
| 태도 — 압박에서 무너지지 않았는가 | 10 |

### 채점 뒤 반드시 줄 것

1. **가장 약했던 답변 3개**를 그대로 인용하고, **고친 문장**을 보여준다
2. **가장 좋았던 답변 1개** — 왜 좋았는지 짚는다. 빼먹지 마라. **잘한 것을 모르면 재현하지 못한다**
3. **다시 답할 기회** — 가장 약했던 질문을 다시 던지고 개선된 답을 받는다
4. **지금부터 할 것** — 반드시 **시점을 붙여서**. "언제까지 무엇을"

### 시점 주의

지원자가 아직 재학 중이고 실제 지원까지 시간이 남았다면 이건 **연습**이다.
준비 부족은 지적하되 반드시 **"지금부터 하면 된다"**로 연결하라. 시간이 남은 사람에게 "자격 미달입니다"로 끝내는 것은 정확하지도 유용하지도 않다.
